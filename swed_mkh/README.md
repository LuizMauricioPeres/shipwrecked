# swed_mkh — Symbol Manifest & Test Generator

Harbour `.prg` symbol analyser, `.mkh` emitter, and automated test generator. Provides the `swed_testgen` binary and a library crate used by the `swed` pipeline.

## Responsibilities

- Two-pass analysis of `.prg` source files: collect symbol **definitions** then resolve **usages**
- Classify every symbol: `Function`, `Procedure`, `Class`, `Public`, `Static`, `Field`
- Emit `.mkh` manifest files into `./cache_maker/` for tooling and LSP lookup
- Generate `#[test]` harnesses from manifests via `swed_testgen`
- Compute MD5 fingerprints of source files for incremental rebuild detection

## Binaries

```
swed_mkh/src/bin/
└── swed_testgen.rs   ← generates Rust test files from .mkh manifests
```

## Library API

| Function | Description |
|---|---|
| `analyse(path) -> MkhManifest` | Two-pass scan of a `.prg` file; returns all symbols |
| `emit_mkh(manifest, out_dir)` | Writes `<name>.mkh` to `out_dir/cache_maker/` |
| `gen_tests(manifest) -> String` | Emits a Rust test file from the manifest |

## Symbol types

| Variant | Description |
|---|---|
| `Function` | Returns a value (`FUNCTION` keyword) |
| `Procedure` | No return (`PROCEDURE` keyword) |
| `Class` | OOP class skeleton |
| `Public` | `PUBLIC` variable declaration |
| `Static` | `STATIC` variable declaration |
| `Field` | `FIELD->name` reference |

## Visibility

| Variant | Meaning |
|---|---|
| `Exported` | Declared at module level, callable from other `.prg` files |
| `Hidden` | Local to current file (`STATIC` functions) |
| `Protected` | Class-bound method |

## Generated test structure

```rust
#[test]
fn test_my_function() {
    // setup PUBLIC globals
    publics_var::pub_declare("N_EMPRESA");
    publics_var::pub_set("N_EMPRESA", HbValue::Integer(0));

    // call transpiled function
    let result = my_function(HbValue::Nil);

    // assert against Harbour NIL-semantics baseline
    assert_ne!(result, HbValue::Nil);   // function returned something
}
```

## Source layout

```
swed_mkh/src/
├── lib.rs          ← public API: analyse, emit_mkh, gen_tests
├── types.rs        ← MkhManifest, MkhEntry, SymbolKind, Visibility
├── analyser.rs     ← two-pass .prg parser (no full AST — symbol-only)
├── emitter.rs      ← .mkh file writer
├── testgen.rs      ← #[test] code generator
└── bin/
    └── swed_testgen.rs  ← binary: reads .prg, writes tests/
```

## .mkh file format

```
# SWed manifest — generated by swed_mkh v0.2.0
# md5: d41d8cd98f00b204e9800998ecf8427e
FUNCTION  my_fn       EXPORTED  2  args
PROCEDURE on_event    EXPORTED  0  args
PUBLIC    n_empresa   —
STATIC    s_cache     —
```
