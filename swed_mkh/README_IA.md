TYPES (types.rs):
  SymbolKind:
    Function   — FUNCTION keyword; returns HbValue
    Procedure  — PROCEDURE keyword; no return
    Class      — CLASS keyword (OOP skeleton)
    Public     — PUBLIC variable declaration
    Static     — STATIC variable declaration
    Field      — FIELD->name reference
  impl: Debug Clone PartialEq

  Visibility:
    Exported   — module-level, callable from other .prg files
    Hidden     — STATIC function; file-local
    Protected  — class-bound method

  MkhEntry — single symbol record
    kind: SymbolKind
    name: String
    arity: Option<(usize,usize)>   — (min,max) for Function/Procedure
    visibility: Visibility
    line: usize
    file: String

  MkhManifest — output of analyse()
    file: String
    md5: String
    entries: Vec<MkhEntry>

ANALYSIS_ALGORITHM (analyser.rs):
  Pass 1 — collect definitions:
    scan for FUNCTION/PROCEDURE/CLASS/PUBLIC/STATIC keywords
    record name, param count, line number, file path
  Pass 2 — collect usages:
    scan for FIELD->name references
    record call sites (for future swed_nm native-call detection)
  MD5 of raw source bytes computed via md5 crate

MKH_FILE_FORMAT (emitter.rs):
  # SWed manifest — generated by swed_mkh v0.2.0
  # md5: <hex>
  # file: path/to/source.prg
  FUNCTION   name  EXPORTED  min  max
  PROCEDURE  name  EXPORTED  0    0
  PUBLIC     name  —         —    —
  STATIC     name  HIDDEN    —    —
  Output dir: ./cache_maker/<name>.mkh

TESTGEN_PATTERN (testgen.rs):
  For each Function/Procedure in manifest:
  #[test]
  fn test_<name>() {
      // setup PUBLIC globals referenced in manifest
      pub_declare("N_EMPRESA");
      pub_set("N_EMPRESA", HbValue::Integer(0));
      // call transpiled function with Nil args
      let result = <name>(HbValue::Nil);
      // assert Harbour NIL-fuzzing baseline
      assert_ne!(result, HbValue::Nil);
  }
  NIL-fuzzing: all args set to HbValue::Nil to test NIL propagation guard

BINARY (bin/swed_testgen.rs):
  Usage: swed_testgen <dir_or_file> [--out tests/]
  1. find_prg_files(dir) via swed_io::directory
  2. analyse(path) → MkhManifest
  3. emit_mkh(manifest, "./cache_maker/")
  4. gen_tests(manifest) → String
  5. write to tests/<name>_test.rs
