## Core Type: `HbValue`

Enum universal para valores dinâmicos:
```rust
pub enum HbValue {
    Nil,           // zero-value padrão
    Logical(bool), // .T. / .F.
    Integer(i64),  // numéricos inteiros
    Float(f64),    // numéricos decimais
    String(String),// UTF-8 (Harbour = bytes, mapeamos para UTF-8)
    Array(HbArray),// 1-indexed, dinâmica, heterogênea
    Date(i32),     // dias desde 1970-01-01
}
```

### Rigor Numérico

#### Divisão (Segurança)
```rust
// Divisor zero → retorna HbValue::Nil (Harbour behavior)
// NÃO panicker, NÃO infinity
Integer(a) / Integer(0) → Nil
Float(a) / Float(0.0) → Nil
```

#### Funções Numéricas Essenciais
- **`hb_trunc(n: HbValue, dec: HbValue) -> HbValue`** — trunca para `dec` casas decimais
- **`hb_round(n: HbValue, dec: HbValue) -> HbValue`** — arredonda para `dec` casas decimais

Exemplo:
```rust
hb_round(3.14159, 2) → 3.14
hb_trunc(3.14159, 2) → 3.14
```

#### Display: Formatação Limpa
Remover zeros à direita e ponto decimal se inteiro:
```
3.00 → "3"
3.50 → "3.5"
3.14 → "3.14"
```

Implementação (pseudo-code):
```rust
impl fmt::Display for HbValue::Float(f) {
    let s = format!("{:.10}", f);           // 10 dígitos significativos
    let s = s.trim_end_matches('0');       // Remove zeros
    let s = s.trim_end_matches('.');       // Remove ponto se não há decimais
    write!(f, "{s}")
}
```

#### Coerção: Promoção Automática
Operadores aritméticos suportam mix Integer + Float:
```rust
Integer(3) + Float(1.5) → Float(4.5)
Float(1.5) + Integer(3) → Float(4.5)
Integer(10) - Float(2.5) → Float(7.5)
Integer(2) * Float(3.5) → Float(7.0)
```

**Regra**: Se algum operando é `Float`, o resultado é `Float`.

#### Formato de Saída
- **Padrão**: DD/MM/YYYY (brasileiro)
- Exemplo: `01/01/1970` para epoch

```rust
impl fmt::Display for HbValue::Date(d) {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        let (year, month, day) = days_to_ymd(*d);
        write!(f, "{:02}/{:02}/{}", day, month, year)
```

#### Operações Suportadas
- **Adição**: `Date(n) + Integer(days)` → nova data (+dias)
- **Subtração**: `Date(d1) - Date(d2)` → `Integer` (diferença em dias)
- **Comparação**: `Date(d1) < Date(d2)` → comparação direta (via dias)

### Tratamento de Strings

#### Formato
- **Harbour**: byte-strings (encoding padrão = DOS/Windows-1252)
- **SWed**: `String(String)` — UTF-8 nativa do Rust
- **Conversão**: Mapeamento implícito em transpilation (codegen normaliza encoding)

#### Concatenação via Operador `+`

```rust
impl std::ops::Add for HbValue {
    fn add(self, rhs: HbValue) -> HbValue {
        match (self, rhs) {
            // Strings → concatenação
            (HbValue::String(a), HbValue::String(b)) => HbValue::String(a + &b),
            
            // Numéricos → adição
            (HbValue::Integer(a), HbValue::Integer(b)) => HbValue::Integer(a + b),
            // ... mix Integer/Float promove para Float
            
            // Datas → adição de dias
            (HbValue::Date(d), HbValue::Integer(days)) => HbValue::Date(d + days),
            
            // Outros: retorna Nil
            _ => HbValue::Nil,
        }
    }
}
```

#### Formatação: `hb_str_format(width, dec)`

Espelha a função `STR()` do Harbour:
- **`width`**: largura total do campo
- **`dec`**: casas decimais (se numérico)
- **Alinhamento**: à direita, preenchido com espaços

```rust
pub fn hb_str_format(value: HbValue, width: HbValue, dec: HbValue) -> HbValue {
    let w = match width { HbValue::Integer(n) => n as usize, _ => 10 };
    let d = match dec { HbValue::Integer(n) => n as usize, _ => 0 };
    
    let s = match value {
        HbValue::Integer(n) => format!("{:.*}", d, n as f64),
        HbValue::Float(f) => format!("{:.*}", d, f),
        HbValue::String(s) => s,
        _ => format!("{}", value),
    };
    
    // Right-align com espaços
    HbValue::String(format!("{:>width$}", s, width = w))
}
```

**Exemplos**:
```rust
hb_str_format(Integer(123), Integer(5), Integer(0)) 
  → String("  123")

hb_str_format(Float(3.14), Integer(8), Integer(2))
  → String("    3.14")

hb_str_format(String("Hello"), Integer(10), Integer(0))
  → String("     Hello")
```

## Design de Escopo Global: `publics_var.rs`

### Hierarquia de Resolução
```
LOCAL (0)  >  STATIC (1)  >  PRIVATE/MEMVAR (2)  >  PUBLIC (3)
```

### Padrão: Singleton com OnceLock + RwLock

**Arquivo**: `publics_var.rs` (Manual/Gerado)

```rust
pub static PUBLICS: OnceLock<RwLock<PublicVars>> = OnceLock::new();

pub struct PublicVars {
    // Known PUBLIC variables (predefinidas ou via DECLARE)
    statics: HashMap<String, HbValue>,
    // MEMVAR dinâmicas (fallback para símbolos desconhecidos)
    memvars: HashMap<String, HbValue>,
}
```

### Lógica de Resolução em Codegen

1. **Símbolo em `PublicVars`** → gera acesso estático:
   ```rust
   PUBLICS.get_or_init(...).read().unwrap().statics["varname"]
   ```

2. **Símbolo desconhecido** → busca dinâmica em runtime:
   ```rust
   PUBLICS.get_or_init(...).read().unwrap().memvars["varname"]
   ```

### Camadas Envolvidas

| Camada | Responsabilidade |
|--------|------------------|
| `scope.rs` | Resolução estática em compilação (transpiler) |
| `publics_var.rs` | Singleton runtime com PUBLIC pool (base/framework) |
| **`publics_project.rs`** | **Especialização**: símbolos específicos do projeto gerado |
| `codegen.rs` | Emite acesso estático vs dinâmico (prioriza project.rs) |
| `swed_rt` | Thread-safe OnceLock + RwLock semantics |

### Estratégia de Override de Globais

#### Localização
- **Runtime**: `publics_var.rs` reside em `swed_rt/src/` (framework padrão)
- **Projeto**: `publics_project.rs` reside em `src/` do projeto **gerado** (especialização)
- Arquivo gerado pelo Codegen, contém símbolos específicos do `.prg`

#### Natureza Opcional

**`publics_project.rs` é OPCIONAL**:
- ✓ Se o projeto define PUBLIC globais explicitamente → Codegen gera o arquivo
- ✓ Se não há globais → arquivo não é criado (fallback para `publics_var.rs`)
- ✓ Se houver mais tarde → regenerar é seguro (merge manual ou sobrescrita)

**Localização quando existe**:
```
projeto/
├── src/
│   ├── publics_project.rs  ← Gerado se houver globais
│   ├── main.rs
│   └── ...
├── src/*.mkp              ← Fontes Harbour
└── Cargo.toml
```

#### Hierarquia: Herança via `pub use`

```rust
// src/publics_project.rs (projeto gerado)
pub use swed_rt::publics_var::*;  // Herda definições padrão

// Sobrescreve ou adiciona símbolos específicos
pub static PROJECT_GLOBALS: OnceLock<RwLock<ProjectGlobals>> = OnceLock::new();

pub struct ProjectGlobals {
    nCounter: HbValue,
    cCompany: HbValue,
    // ... específicos deste projeto
}
```

#### Prioridade no Codegen

**Resolução de símbolo**:
1. ✓ Procura em `publics_project.rs` (projeto específico)
2. ✓ Se não encontra, fallback para `publics_var.rs` (runtime)
3. ✓ Se não encontra, busca dinâmica em MEMVAR

**Código gerado**:
```rust
// Símbolo em publics_project.rs → acesso direto
nCounter  // compila para: PROJECT_GLOBALS.get_or_init(...).read().unwrap().nCounter

// Símbolo desconhecido → fallback dinâmico
nOtherVar // compila para: PUBLICS.get_or_init(...).read().unwrap().memvars["NOTHER_VAR"]
```

#### Integração LSP

**Ordem de varredura**:
1. Indexa `publics_project.rs` (alta prioridade)
2. Indexa `publics_var.rs` (fallback)
3. "Go to Definition" navega para primeiro match em `_project.rs`

**Exemplo**:
```
User clica em: PUBLIC nCounter
LSP busca:     publics_project.rs → Go to Definition (line X)
               (não procura em publics_var.rs se já encontrou)
```

### Macro `m->` (MEMVAR Access)

#### Sintaxe Harbour
```harbour
m->varname       // Acessa variável dinâmica (PUBLIC/PRIVATE)
m->nCounter      // Equivalente a: PUBLIC nCounter
```

#### Regra de Resolução em Codegen

**Sempre busca em Public Vars**:
- `m->foo` → **sempre** consulta `publics_project.rs` ou `publics_var.rs`
- Não segue a hierarquia LOCAL → STATIC → PRIVATE → PUBLIC
- Ignora escopo local (mesmo que exista `LOCAL foo`)

**Código gerado**:
```rust
// Harbour: m->nCounter
// Gerado (sempre PUBLIC):
PUBLICS.get_or_init(...).read().unwrap().memvars["NCOUNTER"]
// ou se encontrar em publics_project.rs:
PROJECT_GLOBALS.get_or_init(...).read().unwrap().nCounter
```

#### Diferença: `varname` vs `m->varname`

```harbour
// Harbour source
LOCAL nX := 10
PUBLIC nX := 20

? nX       // Printa 10 (LOCAL tem prioridade)
? m->nX    // Printa 20 (força PUBLIC)
```

**No Codegen SWed**:
```rust
let n_x = 10;  // LOCAL
let n_x_public = PUBLICS...read().nX;  // PUBLIC (m->)

println!("{}", n_x);           // 10
println!("{}", n_x_public);    // 20
```

### Thread-Safety
- `OnceLock<T>`: Inicialização lazy, uma única vez
- `RwLock<PublicVars>`: Múltiplos leitores simultâneos, escrita exclusiva

## Protocolo de Interface: Get/GetList

### Trait `GetElement`

```rust
pub trait GetElement: Send + Sync {
    /// Renderização visual do elemento
    fn display(&self) -> String;
    
    /// Controle de foco
    fn set_focus(&mut self, active: bool);
    
    /// Getter — lê valor atual
    fn var_get(&self) -> HbValue;
    
    /// Setter — escreve novo valor
    fn var_put(&mut self, val: HbValue);
}
```

### GetList: Vetor de Elementos

```rust
pub struct GetList {
    elements: Vec<Box<dyn GetElement>>,
    active_index: Option<usize>,
}
```

### Vínculo: `bVarBlock` (VarGet/VarPut)

- **Closure Rust** que captura referência mutável ao `HbValue`
- Emulação de `{|| var_name}` do Harbour (lvalue reference)
- Permite:
  ```rust
  let mut x = HbValue::String("Hello".into());
  let var_block = Box::new(|| x); // VarGet
  let var_put_block = Box::new(|v| x = v); // VarPut
  ```

### Active State: THREAD_LOCAL

```rust
thread_local! {
    static GETLIST_ACTIVE: RefCell<Option<Box<dyn GetElement>>> = RefCell::new(None);
}

/// Query da GetList ativa (para reprocessar durante navegação)
pub fn __GetListActive() -> Option<HbValue> {
    GETLIST_ACTIVE.with(|cell| {
        cell.borrow().as_ref().map(|elem| elem.var_get())
    })
}
```

### Fluxo de Interação

1. **Declaração GET**: `GET x PICTURE "9999"` → cria `GetElement`
2. **Compilação**: Codegen gera `Box::new(ConcreteGetWidget { var_block })`
3. **Runtime**: Insert em `GetList.elements`
4. **UI Loop**: 
   ```
   while navegando:
     GETLIST_ACTIVE.set(current_element)
     render()
     handle_input()
     GETLIST_ACTIVE.set(None)
   ```

### Integração com Scope

- `var_block` captura `&mut HbValue` via closure (não precisa de names)
- Funciona tanto com LOCAL, STATIC, PRIVATE, PUBLIC
- `RefCell` garante borrow-checking em runtime (sem `unsafe`)

### Requisitos da Extensão

#### Suporte a Formatos de Arquivo
- **`.mkp`** — Procedures (Harbour puro)
- **`.mks`** — Scripts/utilities
- **`.mkc`** — Classes

#### Funcionalidade 1: Go to Definition

**Símbolos suportados**:
- Funções (locais e globais)
- Variáveis (especialmente mapeadas em `publics_var.rs`)
- Classes e métodos

**Comportamento esperado**:
```
User clica em: call MyFunction()
LSP navega para: definição de MyFunction (arquivo + line)

User clica em: PUBLIC x
```

**Exibir**:
- `ValType()` — tipo do símbolo (Logical, Integer, String, Array, etc.)


#### Funcionalidade 3: Autocompletar Globais (LSP)

**Fonte**: Lê `publics_var.rs` em tempo de indexação

**Comportamento**:
```
User digita: PUBLIC x
LSP sugere: variáveis já declaradas em publics_var.rs
```

**Integração com Codegen**:
- Codegen deve gerar `.deepindex` (metadados JSON) com símbolos públicos
- LSP consome `.deepindex` para populate autocomplete
